# 13 — Content Generation

## Overview

The Content Generation module lets users create AI-powered marketing copy in three categories:

| Type | Platforms |
|------|-----------|
| **Social Media** | Instagram, LinkedIn, Twitter/X, Facebook |
| **SEO Content** | Blog, Google Search, Meta Description, Landing Page |
| **Ad Copy** | Google Ads, Meta Ads, Email Subject Line |

All content is generated by **GPT-4o** via the OpenAI API and returned as structured JSON.

---

## API Specification

### `POST /api/content/generate`

**Request body:**

```json
{
  "content_type": "social_media",
  "platform": "Instagram",
  "variants": 1,
  "brief": {
    "product_name": "Sunrise Bakery",
    "description": "Artisan sourdough baked fresh daily.",
    "target_audience": "Foodies and local families",
    "tone": "casual",
    "keywords": ["sourdough", "fresh"],
    "cta": "Visit us today!"
  }
}
```

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| content_type | `social_media` \| `seo` \| `ad_copy` | ✅ | |
| platform | string | ✅ | See platform list above |
| variants | int 1–5 | — | Default 1 |
| brief.product_name | string | ✅ | |
| brief.description | string | ✅ | |
| brief.target_audience | string | ✅ | |
| brief.tone | `professional` \| `casual` \| `witty` \| `urgent` | ✅ | |
| brief.keywords | string[] | — | Default [] |
| brief.cta | string | — | Optional |

**Response (200):**

```json
{
  "content_type": "social_media",
  "platform": "Instagram",
  "variants": [
    {
      "id": "gen_a1b2c3d4",
      "body": "Fresh sourdough every morning! 🍞",
      "hashtags": ["#sourdough", "#fresh", "#local"],
      "cta": "Visit us today!",
      "character_count": 34
    }
  ],
  "tokens_used": 120,
  "generated_at": "2026-04-02T10:00:00Z"
}
```

**Error codes:**

| Code | Reason |
|------|--------|
| 400 | AI returned invalid JSON |
| 422 | Missing or invalid request fields (Pydantic) |
| 500 | Unexpected server error |

## Platform-Specific Rules

| Platform | Char limit | Hashtags |
|----------|-----------|----------|
| Instagram | 2,200 | 5–8 |
| Twitter/X | 280 | 2–4 |
| LinkedIn | 3,000 | 3–5 |
| Facebook | 63,206 | 2–5 |
| Google Ads headline | 30 | — |
| Meta Ads headline | 40 | — |
| Email subject | 60 | — |
| Meta description | 160 | — |
| Title tag | 60 | — |

## Cost & Rate Limits

- Model: `gpt-4o`
- Max tokens per request: 800
- Estimated cost: **~$0.005 per request** at ~800 tokens
- No built-in rate limiting — add `slowapi` for production
